# Shamba Records System

Shamba Records System is a full-stack farm management platform designed to help administrators and field agents manage agricultural records efficiently.

The system enables field agents to record and update farm information while administrators monitor activities, manage users, and oversee operations through a centralized system.

## Current Status

The project is currently under development.

At the moment, the backend APIs, authentication, authorization, and database integration are being implemented. The frontend interface will be developed in the next phase of the project.

## Features Implemented

- User authentication and authorization
- Admin and agent roles
- Field records management
- Middleware-based access control
- MongoDB database integration
- RESTful API architecture

## Planned Features

- Frontend dashboard and user interface
- Reporting and analytics
- Real-time updates
- Record history tracking
- Responsive design
- Deployment and cloud hosting

## Tech Stack

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication

### Frontend (Planned)
- React.js

## Installation

Clone the repository:

```bash
git clone <repository-url>
```

Install dependencies:

```bash
cd backend
npm install
```

Run the development server:

```bash
npm start
```
